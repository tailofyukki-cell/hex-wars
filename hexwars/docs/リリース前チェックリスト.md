# リリース前チェックリスト

有料リリースの前に、必ずこの表を上から確認すること。済んだら [x] にする。

## 1. 検証用のファイルと入口を消す

動作確認のために作ったもの。**製品に残すと、F12 で誰でも検証用の作戦を遊べてしまう。**
名前はすべて `zz_test` で始まる。

- [ ] `data/campaign/zz_test.cpn` を消す（検証キャンペーン本体）
- [ ] `data/maps/zz_test_quickwin.map` を消す（すぐ勝てる）
- [ ] `data/maps/zz_test_quicklose.map` を消す（すぐ負ける）
- [ ] `data/maps/zz_test_superweapon.map` を消す（超兵器がすぐ作れる）
- [ ] `data/maps/zz_test_hell.map` を消す（HELL の拠点追加）
- [ ] 消し忘れが無いか確認する: `git ls-files | grep zz_test` が何も出さないこと
- [ ] `build_and_deploy.bat` を実行し、配布フォルダ（`HexWars_配布/data/`）にも残っていないこと
      （`data/` は丸ごと写し直すので、元を消せば配布フォルダからも消える）

ファイルを消せば F12 は何もしなくなるが、プログラム側にも検証用の入口が残っている。
完全に外すなら次も消す（消さなくても、ファイルが無ければ働かない）。

- [ ] `src/ui/screens.c` の F12 の作戦選択（`test_cpn_start`、`test_open` を使う部分）
- [ ] `src/ui/app.h` の `test_open, test_idx`
- [ ] `src/core/campaign.c` / `campaign.h` の `test_store`・`test_lab`（作戦データの検証用の設定）
- [ ] `tests/test_core.c` の `test_zz_test_campaign`（ファイルが無ければ自動で飛ばすので、残しても失敗はしない）
