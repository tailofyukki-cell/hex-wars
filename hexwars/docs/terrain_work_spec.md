# 地形の破壊と復旧（工作）

工兵が隣接ヘクスの地形を壊したり、元に戻したりする。
拠点を潰して敵の収入と補給を断つ、道路を切って機甲部隊の足を鈍らせる、
奪ったあとの瓦礫を街に戻す——といった「盤面そのものを動かす」手段。

## 1. ルール

| 項目 | 内容 |
|---|---|
| 実行できる部隊 | `engineer = 1` のユニット（工兵 / 機甲工兵） |
| 対象 | **隣接ヘクスのみ**。自分の足元は対象外 |
| 対象の条件 | 誰も乗っていないこと |
| 破壊 | 対象の地形に `breaks_to` があること。**首都は壊せない** |
| 復旧 | 対象が「壊れている」こと（現地形 ≠ 本来の地形） |
| 費用 | 破壊は無料。復旧は本来の地形の `repair_cost` |
| 手番 | 実行すると工兵の手番は終わる（移動後でも実行できる） |
| 所有 | 破壊も復旧も**所有と占領進捗を白紙に戻す**。復旧しても中立から占領し直す |

### 足元を対象にしない理由、人の居るヘクスを対象にしない理由

破壊先の通行可否は元の地形と揃えてあるので、今のデータでは
足元を壊しても立ち往生はしない。それでも隣接限定にしてあるのは、
将来その前提を破る地形を足しても事故にならないようにする構造側の保険。

人の居るヘクスを対象外にしているのは別の理由で、
籠城する敵の足元を壊して地形防御をタダで剥がせると工兵が強すぎるから。

### 首都を壊せない理由

`game_player_defeated` は「自陣営所有の首都が1つもなければ敗北」を見る。
首都を壊せると工兵1体で勝敗が決まってしまうので `breaks_to` を持たせていない。

## 2. データ

`terrain.def`:

```
breaks_to   = RUBBLE   # 壊されたときになる地形ID（無指定=破壊不可）
repair_cost = 500      # 「この地形に戻す」のに要る資金
```

`repair_cost` は**戻す先の地形**に書く。瓦礫を街に戻す費用は CITY 側に書く。

| 元 | → 破壊後 | 復旧費用 |
|---|---|---|
| 都市 | 瓦礫 | 500 |
| 工場 | 瓦礫 | 800 |
| 飛行場 | 瓦礫 | 700 |
| 港 | 破壊された港湾 | 700 |
| 野戦飛行場 | 瓦礫 | 300 |
| 泊地 | 破壊された港湾 | 300 |
| 道路 | 平地 | 150 |

瓦礫（`RUBBLE`）は収入も補給も無く、占領もできない。
防御補正 +20% だけ残るので、遮蔽としては使える。

### 破壊で通行可否を変えない

港と泊地だけは瓦礫ではなく **破壊された港湾（`RUBBLE_PORT`）** になる。
陸の瓦礫にしてしまうと艦船が入れなくなり、
**海峡や運河を工兵一つで永久に塞げてしまう**から。

「壊しても通れるものは通れるまま」は不変条件としてテストしてある。
新しい地形に `breaks_to` を付けるときは、破壊先の `cost_*` の
「0か否か」を元の地形と揃えること。

`units.def`:

```
engineer = 1   # 隣接ヘクスの地形を破壊・復旧できる
```

工兵は **占領できない**（`can_capture = 0`）。歩兵の代わりにさせないため。

## 3. タイルの状態

`Tile.orig_terrain` にマップ本来の地形を持つ。`terrain != orig_terrain` が
「壊れている」状態で、復旧はここへ戻す。イベントの `TERRAIN:` で変えた地形も
同じ扱いになるので、脚本で落とした橋を工兵が架け直せる。

セーブ形式は v12 で `orig_terrain` を追加した。v11 以前のセーブは
「壊れた地形」という概念が無いので、現地形＝本来の地形として読む。

## 4. CPU

**CPUは復旧しかしない。** 隣接に自陣営側の壊れた地形があり資金が足りていれば直す。

破壊を任せていないのは、自分の進路を自分で潰しかねないうえ、
「今この拠点を壊す価値があるか」の判断に盤面全体の読みが要るため。
復旧だけなら、やって損をすることがない。

## 5. バランス上の注意

- 拠点を潰すと収入が減る。長期戦のマップで両軍が壊し合うと決着が遅くなる方向に働くので、
  ターン上限のあるマップでは sim_ai の決着ターンを見ておくこと
- `SUB_CAPTURE` / `SUB_KEEP_BLD` の副目標は拠点数を数える。
  壊しすぎると自分で達成不能にできてしまうが、これはプレイヤーの選択として許容する
- `objective_count`（拠点n個確保で勝利）も同じく、破壊で母数が減る
