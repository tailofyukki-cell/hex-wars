========================================================
 HEX WARS  素材の差し替えガイド
========================================================

自作のユニット画像・BGM・効果音に差し替えられます。
プログラムを触る必要はありません（data/ の .def を書き換えるだけ）。

読み込めない素材があっても、その部分だけ元の動作に戻るだけで
ゲームは止まりません。うまくいかないときは起動時のログに
「読込失敗」とファイル名が出るので、そこを手がかりにしてください。


--------------------------------------------------------
1. ユニットの画像
--------------------------------------------------------
data/units.def の各ユニットに書きます。

  [unit TANK]
  image  = gfx/units/tank.png        ← 両陣営で同じ絵を使う場合
  image0 = gfx/units/tank_blue.png   ← 自軍（青）だけ差し替える場合
  image1 = gfx/units/tank_red.png    ← 敵軍（赤）だけ差し替える場合

・パスは assets/ からの相対
・使える形式: PNG / JPG（透過を使うなら PNG）
・サイズは自由。ヘクスの大きさに合わせて自動で拡大縮小されます
・正方形の絵を想定しています（縦横比が違うと伸びます）
・陣営の色は絵の左下に付く小さなマーク（自軍=丸 / 敵軍=菱形）で
  区別されるので、絵そのものは色分けしなくても遊べます
・image を書かなければ、従来どおり図形で描画されます


--------------------------------------------------------
2. BGM
--------------------------------------------------------
data/audio.def に書きます。

  [music TITLE]
  file = bgm/my_title.ogg

  [battle]
  file = bgm/my_battle.ogg
  name = 自作テーマ            ← オプション画面に出る曲名

・パスは assets/ からの相対
・使える形式: WAV / OGG / MP3 / FLAC
・[battle] は最大12曲まで増やせます。増やした分がそのまま
  オプションの「戦闘BGM」の選択肢になります
・ループは自動（曲の頭に戻って繰り返します）
・場面固定の枠は TITLE / VICTORY / DEFEAT の3つです


--------------------------------------------------------
3. 効果音
--------------------------------------------------------
同じく data/audio.def です。効果音は「役割ごとのファイル名」と
「セット（フォルダ）」の2段構えになっています。

  [se SHOT]
  file = my_shot.ogg          ← 役割ごとのファイル名

  [seset]
  name = 自作セット
  dir  = sfx/mine             ← assets/ からのフォルダ名

上の例なら assets/sfx/mine/my_shot.ogg が読まれます。

・[seset] を足すと、オプションの「効果音セット」の選択肢が増えます
  （最大6セット）
・あるセットに無いファイルは、いちばん上のセットで自動的に補われます。
  つまり「1つの音だけ差し替えたセット」も作れます
・役割は10種類:
    CURSOR / OK / CANCEL / MOVE_FOOT / MOVE_VEHICLE / MOVE_AIR /
    SHOT / EXPLOSION / CAPTURE / TURN


--------------------------------------------------------
4. そのほか差し替えられるもの
--------------------------------------------------------
・戦闘アニメ    … data/units.def の  anim = gfx/anim/xxx.mp4
                   （mp4 / アニメーションGIF / WebP）
・ブリーフィング絵 … data/campaign/main.cpn の  art = gfx/brief/xx.png
・クリア報酬の絵   … 同  reward = gfx/reward/xx.png
・クリア動画       … 同  reward_video = gfx/anim/xx.mp4
・画面の文言       … data/text_ja.def


--------------------------------------------------------
5. ゲームそのものを別物に作り替えたいとき
--------------------------------------------------------
ファンタジー版・SF版などに丸ごと作り替える手順は
docs/別ゲームの作り方.md にまとめてあります。
（どのファイルを触るか、内部名の読み替え表、各種上限、
  C を触らないと変えられないものの一覧）


--------------------------------------------------------
6. 元の音源を作り直したいとき
--------------------------------------------------------
同梱の音は tools/gen_audio.py で自動生成しています。
Python があれば実行するだけで assets/bgm/ と assets/sfx/ に
作り直されます（追加ライブラリ不要）。
