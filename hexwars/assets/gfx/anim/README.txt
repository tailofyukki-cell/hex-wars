動画の追加方法（戦闘アニメ / クリア報酬 / エンドロール）
========================================================

1. 対応形式
   - mp4 / webm / mov / mkv / avi / m4v  … ffmpeg で自動変換して再生
   - アニメーションGIF (.gif)            … そのまま再生（変換不要）

   ※ mp4 等を使うには ffmpeg が必要です。
      - PATH に ffmpeg があればそれを使います（`ffmpeg -version` で確認）
      - または tools/ffmpeg/ffmpeg.exe に置いてください（配布時はこちらが確実）
      ffmpeg が無い場合、mp4 は再生されず従来表示（静止画/HPバー演出）になります。

   【仕組み】初回再生時に ffmpeg で PNG 連番へ展開し cache/anim/ に保存します。
   2回目以降はキャッシュを再利用するので待ち時間はありません（元動画を更新すると
   自動で作り直します）。再生時は1枚ずつ読み込むので長い動画でもメモリを食いません。
   変換時は 15fps・横最大720px・最大900フレーム(=60秒) に落とします。

2. 用途ごとの設定

   (A) 戦闘アニメ（ユニット毎に指定できる）
       data/units.def の各ユニットに書きます。

         [unit TANK]
         anim = gfx/anim/tank_attack.mp4

       ゲーム内でオプション →「戦闘アニメを動画で再生」を ON にすると、
       そのユニットが攻撃したときに再生されます（既定は OFF）。
       未指定・読込失敗のユニットは従来のHPバー演出になります。
       ※「戦闘アニメ」自体が OFF だと動画も再生されません。

   (B) 各マップのクリア報酬（作戦ごとに指定できる）
       data/campaign/main.cpn の各ノードに書きます。

         [node M01]
         reward       = gfx/reward/m01.png      # 静止画（従来）
         reward_video = gfx/anim/m01_clear.mp4  # 動画（指定すると動画が優先）

   (C) エンドロール（キャンペーン全クリア後）
       次のどちらかを置くと、クレジットの背景として再生されます（任意）。

         assets/gfx/anim/endroll.mp4
         assets/gfx/anim/endroll.gif

       動画が無くてもクレジットは流れます（文字だけ）。
       クレジットの文面は data/text_ja.def の END_L01 以降を編集してください
       （連番。未定義の番号で終端。行頭 '@' は見出し＝大きい文字）。

3. 同梱のサンプル
   sample_land.mp4 / sample_land.gif … 戦車(TANK)に割当済み（mp4の動作確認用）
   sample_sea.gif                    … 戦艦(BATTLESHIP)に割当済み
   いずれも動作確認用のプレースホルダです。実際の動画に差し替えるか、
   units.def の `anim =` 行を削除してください。

4. 推奨
   - 解像度: 横640〜1280px（画面に合わせて自動で拡大縮小されます）
   - 長さ  : 戦闘アニメは1〜3秒、エンドロールは30〜60秒程度
   - 事前変換したい場合（初回の待ちを無くす）:
       ffmpeg -i input.mp4 -vf "fps=15,scale=720:-2" cache用… ではなく、
       単に一度ゲーム内で再生すればキャッシュされます。
